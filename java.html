Java Programming Workshop

Documented Learning Sessions: From Basics to OOP & Mini Project

Day 1: Programming Fundamentals

Duration: 2 hrs

  • Java syntax, variables, operators, loops, and conditionals.
  • Programs: factorial, prime checking, Fibonacci sequences.
  • Practiced writing small functions and using control structures.
  • Learned importance of code readability and comments.
  • Tips: Dry-run logic on paper before compiling.
  • Key Takeaways: Solid Java basics, solving problems with loops, ready for OOP.

Day 2: Functions & Recursion

Duration: 2 hrs

  • Implemented factorial & Fibonacci using recursion.
  • Learned base cases, stack behavior, and recursion vs loops.
  • Broke problems into smaller reusable functions.
  • Tips: Monitor stack limits to avoid overflow.
  • Key Takeaways: Modular code, recursion foundation for advanced OOP.

Day 3: Classes & Objects

Duration: 2 hrs

  • Created Car class with attributes and methods.
  • Instantiated multiple objects and simulated behavior.
  • Tips: Start small with simple classes first.
  • Key Takeaways: Encapsulation of data & behavior, real-world modeling.

Day 4: Encapsulation & Abstraction

Duration: 2 hrs

  • Built BankAccount class with private fields & getters/setters.
  • Implemented deposit, withdraw, display with validation.
  • Discussed abstraction & simplifying interfaces.
  • Tips: Always validate inputs in setters.
  • Key Takeaways: Protected object data, applied abstraction effectively.

Day 5: Inheritance

Duration: 2 hrs

  • Created Person (base) and Student (derived) classes.
  • Practiced overriding and using super().
  • Tips: Avoid very deep inheritance hierarchies.
  • Key Takeaways: Code reuse, understanding parent-child relationships.

Day 6: Polymorphism

Duration: 2 hrs

  • Implemented abstract Shape class with Circle & Rectangle subclasses.
  • Demonstrated runtime polymorphism with area calculation.
  • Tips: Use polymorphism to scale systems and reduce redundancy.
  • Key Takeaways: Designed flexible systems, practiced overriding & abstract classes.

Day 7: Mini Project – Library Management System

Duration: 3 hrs

  • Designed Book, Member, and Library classes.
  • Implemented encapsulation, inheritance, and polymorphism together.
  • Tested and debugged system end-to-end.
  • Tips: Plan class relationships before coding.
  • Key Takeaways: Built portfolio-ready OOP project, gained real-world design experience.
