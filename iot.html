PCB & IoT Workshop

Documented Learning Sessions: ESP8266, IoT Systems, and PCB Design

Day 1: IoT Module – Getting Started with ESP8266

  • Topics: Introduction to ESP8266, GPIO, Wi-Fi, IoT applications.
  • Setup: Installed Arduino IDE, added ESP8266 board libraries.
  • Hands-on: Blink internal & external LEDs with ESP8266.
  • Key Features Learned: Microcontroller basics, Arduino IDE usage, circuit connections.

Day 2: IoT Module – Wi-Fi & Web Server Basics

  • Topics: Wi-Fi concepts, SSID, IP addresses, secure passwords.
  • Hands-on: Connected ESP8266 to Wi-Fi, printed IP, created a simple LED control web server.
  • Key Features Learned: IoT networking, web server creation, remote hardware control.

Day 3: IoT Module – Sensor Integration & Monitoring

  • Topics: Recap of Wi-Fi/web server setup, ultrasonic sensor interfacing.
  • Hands-on: Distance measurement on Serial Monitor & live web page updates.
  • Key Features Learned: Sensor integration, real-time monitoring, remote sensing with IoT.

Day 4: IoT Module – IoT Mobile App Development

  • Topics: Brainstorming IoT projects, MIT App Inventor basics.
  • Hands-on: Built an Android app to display sensor data & control ESP8266 outputs.
  • Key Features Learned: No-code app development, IoT hardware–mobile integration, end-to-end IoT ecosystem.

Day 5: PCB Designing – Fundamentals & Schematic Design

  • Topics: Designed AC-to-DC converter schematic, learned PCB layers, vias, footprints.
  • PPT Session: Real-life PCB applications & best practices.
  • Key Features Learned: Circuit schematic fundamentals, PCB basics, industry insights.

Day 6: PCB Designing – Layout & Routing

  • Topics: Converted schematic to layout, placed components, routed traces.
  • Hands-on: Performed DRC checks, practiced individual PCB layouts.
  • Key Features Learned: PCB layout skills, error checking, manufacturability considerations.

Day 7: PCB Designing – Advanced Circuit & Final Review

  • Topics: Designed DC motor speed controller schematic & layout.
  • Hands-on: Completed routing, simulation, design optimization.
  • Key Features Learned: Applied PCB design to real-world projects, advanced routing, fabrication readiness.
