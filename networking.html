Networking Workshop

Documented Learning Sessions: 7-Day Networking Module

Day 1: Introduction to Networking

  • Building blocks: sender, receiver, transmission medium, message & protocol.
  • Modes of communication: simplex, half-duplex, full-duplex (e.g., walkie-talkies vs video calls).
  • Analog vs digital signals: why digital dominates (noise immunity, easier processing).
  • Essential characteristics: speed, accuracy, reliability, security.
  • Real-world example: How a WhatsApp message travels as packets through networks.

Day 2: Types of Network & Nature of Data

  • Network types: LAN, MAN, WAN, PAN (home Wi-Fi to global ISPs).
  • Client-server vs peer-to-peer models & scalability impacts.
  • Bandwidth & latency trade-offs (e.g., high-frequency trading needs ultra-low latency).
  • Data types: oriented (structured), observed (sensor), inferred (analytics/predictions).
  • IoT ecosystems where multiple network types coexist.

Day 3: The OSI Model Demystified

  • 7-layer OSI stack: Physical, Data Link, Network, Transport, Session, Presentation, Application.
  • Protocol examples: Ethernet, IP, TCP/UDP, SSL/TLS, HTTP/HTTPS, FTP.
  • Encapsulation & de-encapsulation: how data is wrapped/unwrapped at each layer.
  • Hands-on: Tracing packet journey using ping & traceroute.

Day 4: Inside the Web: HTTP & DNS

  • DNS as the internet’s phonebook: converting domains to IP addresses.
  • HTTP/HTTPS methods: GET, POST, PUT, DELETE; RESTful API usage.
  • Caching & response codes: 2xx, 3xx, 4xx, 5xx.
  • Lab: Using nslookup & browser DevTools for DNS lookup observation.

Day 5: Revision & DHCP in Action

  • Static vs dynamic IP addresses.
  • DHCP handshake: Discover → Offer → Request → Acknowledge.
  • Checked live router DHCP lease table and dynamic IP assignment.

Day 6: Low-Level Protocols & Diagnostics

  • ARP: maps IP addresses to MAC addresses in a LAN.
  • ICMP: foundation for ping & traceroute.
  • DHCP Acknowledge: final IP allocation confirmation.
  • Practical: Tracing packets and identifying network bottlenecks.

Day 7: Final Integration & Real-World Networking

  • Combining OSI knowledge, protocols, and tools.
  • Case study: Netflix streaming & Content Delivery Networks.
  • Basics of cybersecurity: encryption, firewalls, VPNs.
  • Discussion: Q&A and recap of all networking concepts.
